# LankaTrails 🌿

A local tour and travel guide mobile application for Sri Lanka, built with React Native (Expo).

## Framework

- React Native with Expo SDK 54
- Expo Router for navigation
- TypeScript

## Features

- Browse Sri Lanka attractions (Historical, Nature, Hotels)
- Category filtering and search
- Detailed attraction pages
- Favorites bookmarking system (AsyncStorage)
- GPS navigation via Google Maps
- Bottom tab navigation

## Dependencies

- expo-router
- @react-native-async-storage/async-storage
- expo-location
- expo-linking
- expo-status-bar

## How to Run

### Prerequisites

- Node.js (v20+)
- Expo Go app on Android/iOS device

### Steps

1. Clone the repository

git clone https://github.com/Nnavodya/LankaTrails.git

2. Install dependencies

npm install 3. Start the development server
npx expo start --tunnel 4. Scan the QR code with Expo Go app
